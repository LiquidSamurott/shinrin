================================================================================
                    SHINRIN AI - MODEL FILES GUIDE
================================================================================

📁 LOCATION: src-tauri/models/

This folder contains the AI model files required for the Shinrin application's
AI Assistant and Speech-to-Text features.

================================================================================
                          REQUIRED MODELS
================================================================================

1. Qwen3-4B-Q6_K.gguf (AI Assistant)
   Size: ~3.3 GB
   Status: NOT INCLUDED IN REPO (Download separately)

2. ggml-small.bin (Speech-to-Text)
   Size: ~466 MB
   Status: NOT INCLUDED IN REPO (Download separately)

The application expects these files to be present in this folder. Without them,
the AI Assistant and Speech-to-Text features will not work.

================================================================================
                    DOWNLOAD INSTRUCTIONS
================================================================================

OPTION 1: Download from Hugging Face (Recommended)
---------------------------------------------------
1. Visit: https://huggingface.co/Qwen/Qwen3-4B-GGUF
2. Download: Qwen3-4B-Q6_K.gguf
3. Visit: https://huggingface.co/ggerganov/whisper.cpp
4. Download: ggml-small.bin
5. Place both files in this folder (src-tauri/models/)

OPTION 2: Use Smaller Models (If you have limited storage)
-----------------------------------------------------------
Alternative AI models that work with Shinrin:

| Model File                          | Size     | Quality  |
|-------------------------------------|----------|----------|
| Qwen3-4B-Q6_K.gguf                 | ~3.3 GB  | Best     |
| Qwen3-4B-Q4_K_M.gguf               | ~2.5 GB  | Good     |
| Qwen3-4B-Q3_K_M.gguf               | ~1.8 GB  | Medium   |
| Qwen3-4B-Q2_K.gguf                 | ~1.0 GB  | Basic    |

Alternative STT models (whisper.cpp):

| Model File          | Size     | Speed    | Accuracy |
|---------------------|----------|----------|----------|
| ggml-tiny.bin       | 75 MB    | Fastest  | Basic    |
| ggml-base.bin       | 142 MB   | Fast     | Good     |
| ggml-small.bin      | 466 MB   | Medium   | Very Good ⭐ |
| ggml-medium.bin     | 1.5 GB   | Slow     | Excellent|

Download STT models from: https://huggingface.co/ggerganov/whisper.cpp/tree/main

================================================================================
                    STEP-BY-STEP INSTALLATION
================================================================================

STEP 1: Download the Model Files
---------------------------------
Choose one of the following methods:

A) Using Browser:
   1. Go to https://huggingface.co/Qwen/Qwen3-4B-GGUF
   2. Click on "Files" tab
   3. Download Qwen3-4B-Q6_K.gguf
   4. Go to https://huggingface.co/ggerganov/whisper.cpp
   5. Download ggml-small.bin

B) Using Command Line (Windows PowerShell):
   ```powershell
   # Navigate to models folder
   cd src-tauri/models
   
   # Download AI model
   curl -L https://huggingface.co/Qwen/Qwen3-4B-GGUF/resolve/main/Qwen3-4B-Q6_K.gguf -o Qwen3-4B-Q6_K.gguf
   
   # Download STT model
   curl -L https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin -o ggml-small.bin
   ```

C) Using Command Line (macOS/Linux):
   ```bash
   # Navigate to models folder
   cd src-tauri/models
   
   # Download AI model
   wget https://huggingface.co/Qwen/Qwen3-4B-GGUF/resolve/main/Qwen3-4B-Q6_K.gguf
   
   # Download STT model
   wget https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
   ```

STEP 2: Verify File Integrity
------------------------------
Check that the files are complete:

| File                    | Expected Size     |
|-------------------------|-------------------|
| Qwen3-4B-Q6_K.gguf     | ~3.3 GB (3,544 MB) |
| ggml-small.bin         | ~466 MB            |

If the files are smaller than expected, the download was interrupted.
Delete the partial files and try again.

STEP 3: Place Files in Correct Location
----------------------------------------
Ensure both files are in:
```
src-tauri/models/
├── Qwen3-4B-Q6_K.gguf
└── ggml-small.bin
```

STEP 4: Launch Shinrin
-----------------------
Start the application:
```bash
pnpm tauri dev
```

The models will load automatically on first use.

================================================================================
                    SYSTEM REQUIREMENTS
================================================================================

Minimum Requirements:
----------------------
- RAM: 8 GB (16 GB recommended for 3.3 GB model)
- Storage: 5 GB free space for both model files
- CPU: Any modern multi-core processor
- GPU: Optional (for faster inference)

STT Requirements:
------------------
- The ggml-small.bin model works on CPU
- No GPU required for speech recognition
- ~500 MB additional RAM during use

Performance Tips:
------------------
- Use Q3 or Q2 models if you have limited RAM
- Use smaller STT models (tiny/base) for faster speech recognition
- The Q6 model provides the best quality but uses more memory
- The small STT model balances speed and accuracy
- Close other applications to free up memory

================================================================================
                    TROUBLESHOOTING
================================================================================

Q: The AI Assistant doesn't respond
-----------------------------------
A: Check if the model file exists and is not corrupted:
   - Verify the file is in: src-tauri/models/Qwen3-4B-Q6_K.gguf
   - Check file size: Should be ~3.3 GB
   - If file is incomplete, re-download it

Q: Speech-to-Text doesn't work
------------------------------
A: Common causes:
   1. Missing ggml-small.bin file
   2. Model file is corrupted - Re-download
   3. Check the STT model path in configuration

Q: "Failed to load model" error
--------------------------------
A: Common causes:
   1. Insufficient RAM - Try using a smaller model (Q3 or Q2)
   2. Corrupted file - Re-download the model
   3. Path issues - Make sure the file is in the correct folder
   4. Permissions - Ensure the app can read the files

Q: The app is using too much RAM
---------------------------------
A: Switch to smaller models:
   1. Download smaller models:
      - Qwen3-4B-Q2_K.gguf (1.0 GB)
      - ggml-base.bin (142 MB)
   2. Rename or replace the existing files
   3. Restart the application

Q: Slow response times
----------------------
A: Try these optimizations:
   1. Use smaller models (Q3/Q2 for AI, base/tiny for STT)
   2. Close other applications to free up CPU
   3. If available, use GPU acceleration
   4. For STT, smaller models are faster

Q: "Model not found" error
---------------------------
A: Make sure the files are named exactly:
   - Qwen3-4B-Q6_K.gguf (case sensitive on some OS)
   - ggml-small.bin (case sensitive on some OS)
